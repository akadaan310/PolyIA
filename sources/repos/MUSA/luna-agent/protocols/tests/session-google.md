# Session program — Google test

seurl://test/google-session?units=not-unit,composition,url-machine,ramz&mode=probe

## Purpose
Send what we built out through a stateless Google session. See how it
comes back. One session, no sign-in, no history access from here — the
web answers, we read the shape of the answer.

## The battery
Each probe: run it, record what comes back, mark CORROBORATES / SURPRISES /
SILENT (nothing in the wild).

1. "content-addressed functions" — does the wild have ¬-units by another name?
2. "programmable URLs" purl — who else builds programs as URLs?
3. "unified program representation" simplest composable unit — any prior art
   for the ¬-unit (one operation, one id, one url)?
4. "agent mail" email for AI agents — the landscape we mapped; confirm live.
5. "openclaw" agent harness — the harness he named; what is it, really?
6. "thousand browser sessions" shared state machine — anyone running N
   sessions on one state machine?

## Reading the results
- CORROBORATES: the wild independently built our shape. We are not alone;
  study their choices.
- SURPRISES: the wild contradicts or outflanks us. Take the opposite
  values (mapping).
- SILENT: nobody built it. The territory is ours.
