# Nomenclature registry

Version: `snad/1`. Labels describe computational objects; they do not settle linguistic or theological interpretation.

| Name | Definition | Distinction |
| --- | --- | --- |
| Source | Versioned origin of a record or annotation | Not the current interpreter |
| Locus | Stable corpus address `quran:S:A` | Not a detector-selected highlight |
| Unit | A supplied turn or adapter-generated source token | Not necessarily a sentence or semantic proposition |
| Speaker | Explicitly annotated producer identity | Not grammatical first/second/third person |
| Addressee | Explicitly annotated target of an utterance | Not every second-person token |
| Referent | Annotated entity referenced in discourse | Not necessarily a speaker or addressee |
| Narrator | Explicitly annotated narrative voice | Not automatically the author |
| Frame | Root or nested quotation context | Quote cues do not resolve speaker identity |
| Person / number | Morphological annotation of a source unit | Not stable discourse identity |
| Tense / aspect | Distinct supplied grammatical fields | A PERF tag alone does not establish event time |
| Transition | Directed adjacent-unit comparison with typed change labels | Not a proven intentional rhetorical act |
| Provenance | Source/unit/frame/transition dependency graph plus evidence | Not independent validation of the source |
| Morphism | Typed path with source and target endpoints | This path algebra is a model, not a category of all discourse meanings |
| Structural signature | Defined projection used for finite equivalence experiments | Collisions and information loss are expected |
| Motif | Repeated finite transition-label sequence | Not a discovered universal grammar |
| Confidence | Uncalibrated annotation/evidence-quality score | Not probability of truth or intent |
| Coverage | Count with explicit task-specific denominator | Addressability is not successful detection or audio verification |

Inherited ISNAAD names (`istihdar`, `raj-al-jidhr`, `ribat`, `tabaqat-al-isnad`, `jisr-al-naba`, `alsinat-al-khalq`, `rusul-echo`, `nasikh-mirror`) remain source labels in compatibility evidence. Generic SDK operators do not inherit the interpretations those names may suggest.
