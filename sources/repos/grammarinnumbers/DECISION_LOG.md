# Decision Log

| ID | Date | Decision | Reason |
|---|---|---|---|
| GIN-D-001 | 2026-10-08 | The `grammarinnumbers` repository root *is* the independent `grammar-in-numbers/` workspace of the mandate. Mandate directories map as: `BOOK_CONTENT/` → `book/content/`, `SDK/` → `sdk/`, `EXPERIMENTS/` → `experiments/`, `WEB/` → `book/site/` + `book/tools/`, `TESTS/` → `sdk/tests/` + `book/tests/`, `BIBLIOGRAPHY/` → `book/content/bibliography.json`. | The repository was empty and dedicated to this publication; the CGT layout (book/sdk/experiments) is the family convention and keeps both publications navigable the same way. |
| GIN-D-002 | 2026-10-08 | The CGT repository is read-only. It was read (ledger, book tooling) and never written; `git status` in the CGT checkout was verified clean at the end of the session. No CGT code is imported at runtime or build time. | Mandate §34. |
| GIN-D-003 | 2026-10-08 | Primary experimental metric: counted steps under a stated model (rules, flips, gates/depth, 32-bit limb operations, division steps). Wall-clock only in `_s` fields. | Same discipline as CGT-D-003; mandatory bit complexity (mandate §26). |
| GIN-D-004 | 2026-10-08 | SDK and experiments: Python standard library only. Machine experiments additionally use the host's gcc, clang, javac/java, rustc, go and node, with versions recorded. | Self-containment; the machine questions cannot be answered without real toolchains. |
| GIN-D-005 | 2026-10-08 | Inverse operations are modelled as **converse relations**, and admissibility as |Sol| = 1. "Undefined" is never used as a final answer. | Mandate §10: 1/0 and 0/0 are different failures; the converse view makes that precise and uniform. |
| GIN-D-006 | 2026-10-08 | A **typing** layer was added between syntax and semantics (four layers instead of CGT's three). | Literals such as 0.5 in ℤ and 2147483648 in int32 fail neither syntactically nor semantically. |
| GIN-D-007 | 2026-10-08 | The IEEE simulator computes exactly on rationals and rounds once. It is validated against the host's hardware results *and flags*, not only against Python floats. | Python cannot read flags and raises on x/0; hardware is the only independent oracle available. |
| GIN-D-008 | 2026-10-08 | After EXP-005's first run (101 flag mismatches, all signaling-NaN operands) the simulator was extended to model signaling NaNs, and the run repeated. The failed run is recorded (GIN-REJ-002). | Corrections preserve provenance. |
| GIN-D-009 | 2026-10-08 | Exponents are evaluated in exact ℤ in every domain. | 0^−1 in ℤ/6 had evaluated to 0 (GIN-NEG-013): exponentiation is an action of the integers, not a ring operation. |
| GIN-D-010 | 2026-10-08 | EXP-012's integer-representability search is exhaustive only for p ≤ 11; for binary32/64 it checks 1 … 2¹⁶ and a 4,096-wide window below 2ᵖ. | A full search to 2²⁴ with exact rationals did not finish in reasonable time; the window plus the proof (PROP-030) is sufficient and stated. |
| GIN-D-011 | 2026-10-08 | EXP-011 lifts CPython's int–string conversion cap (`sys.set_int_max_str_digits(0)`) only to build reference values, and records the default cap. | The cap is itself an observation about cost (GIN-OBS-014). |
| GIN-D-012 | 2026-10-08 | Euclid average-step data are reported against Porter's formula with the convention offset (−1) stated rather than "corrected away". | Different counting conventions; GIN-OBS-011. |
| GIN-D-013 | 2026-10-08 | References are verified at metadata level by web search where possible and marked per entry (`metadata-verified`, `secondary-only`, `unverified`). An unverifiable "Foster 1947" was dropped in favour of Smullyan 1961 and Forslund 1995. | No invented citations. |
| GIN-D-014 | 2026-10-08 | The book's build pipeline follows CGT's design (Markdown + KaTeX at build time, status-badged environments, build fails on any integrity error, executed examples checked at build time) but is a separate implementation in `book/tools/`. The visual identity shares CGT's typography and paper palette with a different accent (ultramarine instead of emerald). | Mandate §30, §34: same intellectual family, independent work. |
| GIN-D-015 | 2026-10-08 | The website's laboratory runs a JavaScript port of the evaluator (`book/site/assets/js/gin-core.js`), and every lab result class is checked against fixtures generated from the Python SDK (`book/data/lab_fixtures.json`) by `book/tests`. | A lab that disagrees with the SDK would be a second, unchecked theory. |
