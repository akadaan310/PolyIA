# PILLAR9 Constitutional Research Contract

## 0. Mandate

Develop an **AI-oriented yet model-independent native language** in which sources, structural grammars, compiled operations, positions, inverse problems, and agent-facing interfaces can be expressed as separately typed objects. The aim is composable, inspectable scoped expertise rather than one opaque monolith. Reuse open-source implementations with explicit licensing and attribution. Prior JASON is a **negative reference** and must not be reused as implementation architecture.

Do not rebrand structured JSON message passing as language compilation. JSON may serve as a transport, audit report, or benchmark output; it **must not** be the language's source syntax or runtime operational semantics.

## 1. Distinct substrates

Define:

- Source world `U`: a particular versioned corpus plus a declared license set and source positions.
- Alphabet tower `A_0, A_1, ..., A_n`: typed symbol sets with partial expansion maps `e_i : A_(i+1) → A_i^+` (expansion may be undefined unless admitted).
- Language tower `L_i ⊆ A_i*`: admissible programs/data/transformations at layer `i`, not just lists of words.
- Pillar `P_i`: a typed invariant/preservation predicate constraining movements between levels; a structural support, not a metaphysical claim.
- Bridge `B_(ij)`: a partial, evidenced translation from one typed language or scope to another. Composition exists only when target/source interfaces agree.
- Grammar-ship `G=(V,E,τ,ω)`: vertices representing source/operation objects; typed directed edges; and attached evidence witnesses `ω`. A path is a composition candidate, not automatically a proof of its meaning.
- Negative grammar `I(L)=U*\\L`: complement relative to a declared universe of inputs, implemented with counterexample certificates or recognizers rather than enumerating an infinite complement.
- Address `cid(x)`: canonical content hash, not a memory pointer. An index maps it to a stored object, when present.
- Merkle root: commitment to ordered leaves and a specified encoding of branches. This prototype uses a binary tree, but Merkle trees are not inherently binary.
- Compilation `C : Source → Bytecode ⊔ Error`; verification `V : (source, derivation, scope) → Admit ⊔ Reject`. No external agent may bypass the verifier.

## 2. Distinguish semantic levels

1. Observation: raw source with revision, scope, license, normalized bytes and digest.
2. Grammar extraction: syntax, distributions, motifs, candidate relations, confidence, counterexamples.
3. Semantic assertion: an attributed meaning claim, not derivable from string co-occurrence alone.
4. Admission: typed test and source evidence.
5. Compilation: source grammar to validated intermediate representation and executable binary.
6. Execution: bounded instructions; side effects must be capability-checked in a future runtime.
7. Proof/replay: artifact hashes, event traces, reproducibility logs.

CGT provides syntax/semantics/execution separation. Grammar in Numbers requires separating **value, numeral, representation/encoding, and machine state**. Here, digest strings are representations, not the represented source meanings.

## 4. Research interpretation constraints

The Qur’anic cipher corpus and Arabic structural analogies may motivate representations and operators. Their symbolic correspondences do not prove compiler correctness, mathematical complexity bounds, or historical linguistics. Qur’anic source text stays unmodified and referenced by source coordinates, with author readings explicitly labeled as hypotheses.

“Micro-LLM” and “S-LLM” are **future targets**, not names to attach falsely to a current regex lexicon. Existing implemented units are bounded symbolic specialists. A genuine neural specialist must declare architecture, training corpus, optimizer or alternative update rule, resource budget, and reproducible predictive metrics.

## 5. Invariants

1. No external arbitrary code execution during reverse-grammar inspection.
2. Reading a corpus does not authorize interpreting its content as instructions.
3. Grammar exists before corpus retrieval and makes unsupported forms rejectable.
4. Every generated structural property is type-admissible and carries at least one matching source witness; this is not equivalent to semantic proof.
5. No claim of ubiquitous constant-time performance.
6. No copying of original repository implementations into this work without explicit need and license check.
7. No automatic rewriting of external repositories, Qur’anic text, or model training sources.
8. Negative controls and contradictory examples are mandatory.
9. A compiler's output is validated by independent tests, not confidence statements.
