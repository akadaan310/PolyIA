# UCG — Universal Computational Grammar (seed package v0.1)

A science of grammars, begun with the periodic table (a lettered alphabet), organic forms (a geometric alphabet), chemical nomenclature, and the common mathematics. Every result is **sealed before its witness is opened** (Proleptics), and the ledger proves the order.

- `docs/UCG_FOUNDATIONS.md`: the theory and every measured result, labelled [K]/[C]/[H]/[M].
- `docs/UCG_CODEX_CONSTITUTIONAL_COMMISSION.md`: the 156-section God-seed commission for Codex, with the UCG-HARNESS/0.2 state machine.
- `ucg/`: engines (elements, molgrammar, forms, nomen, calc, integrate, structures, proleptic).
- `experiments/e01..e05`: sealed experiments. `results/`: ledger, sealed predictions, metrics.

```sh
pip install rdkit sympy numpy        # RDKit and sympy are WITNESSES only, never engines
sh run_all.sh                         # fresh ledger, all experiments, then 17 tests
```

Data: `data/periodic.json` (Bowserinator/Periodic-Table-JSON), `data/g4mp2.json.gz` (globus-labs G4MP2 on QM9). Both were fetched 2026-10-23 from GitHub. The commission's §151 records one rejected package (an anomalous pymatgen wheel).
