# External source status and licensing

- User-provided screenshots: inspected as style/interaction references; not redistributed in this package.
- Bright-star sample: 20 Hipparcos apparent directions from previously packaged source, traced to d3-celestial 0.7.35 BSD-3-Clause / Olaf Frohn (source attribution preserved). Distances are fictional display radii.
- New code: authored for ASTRA in this release; no copied Unreal/Isnad renderer source.
- Original WAVs: `tools/generate_audio.py` reproducibly generates owned synthetic PCM.
- NASA media: no media downloaded or used in this release. NASA media guidance: https://www.nasa.gov/nasa-brand-center/images-and-media/.
- Gaia: no bulk download. https://gea.esac.esa.int/archive/.
- JPL Horizons: API researched but not integrated. https://ssd-api.jpl.nasa.gov/doc/horizons.html.
- Web Audio references: https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API and https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Web_audio_spatialization_basics.
- Vibration limitations: https://developer.mozilla.org/en-US/docs/Web/API/Vibration_API.

Retain attribution and confirm license compatibility before any commercial redistribution of later imported external assets.
