# TRE/TREE — Formal Machine Hierarchy and Engine Substrates, v0.1

**Research commission dated 2026-10-22.** Independent, zero-dependency computational experiment. **No changes to HOMELESS/Dark, Unreal, Substrate University, PURL, CGIT, PILLAR9, or CLOCK9 repositories.**

This packet is the foundation **before building the renderer or physics engine**. `tre/core.py` is a deterministic, replayable, two-tree growth transition system with typed support relationships, virtual resource conservation, counterexample admission, and domain-separated content IDs. `tre/corpus.py` defines grammar-before-ingestion and evidenced bridge eligibility (structural evidence only). `tre/cgit.py` implements minimal immutable content-addressed object relationships and integrity verification (not Git protocol).

## Quick start

```bash
cd TRE_TREE_FOUNDATIONS_V01
PYTHONPATH=. python3 -m unittest discover -s test -v
PYTHONPATH=. python3 examples/run.py
```

No third-party packages. The demo writes `results/tree_fixture.json`. The engine study is **not** a renderer, a physics solution, a biological plant model, a real OS/VM isolation boundary, or an Android/iOS build. No external open-source engine source code has been copied. Test totals concern these limited contracts only.
