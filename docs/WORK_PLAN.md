2. Stale guidance acknowledgement/application: revision and action scope prevent silent overwrite.
3. Serialized hashes without actual bytes: verification recomputes artifacts and reducer state.
4. All invalid numerical points or missing premises: explicit inconclusive/refused result, never success.
5. A source is missing or historically labelled preview: source coverage records it, never silently omits it.
