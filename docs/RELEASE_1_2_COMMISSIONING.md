# Runtime 1.2.0 commissioning increment

This release extends the live commissioning service with a bounded native
language, source-preserving intake and a versioned Astra adapter. It constructs
the first Book of Forms edition under the owner's clarification. The full Option A
commission, all B/C and inherited obligations remain **NOT_COMMISSIONED**.

## Implemented behavior

- `experiment.run` admits `native`, `intake` and `astra` through fixed dispatch.
  Each records the actual dependency source bytes and loaded-code identity.
  Replay and exact retries inspect captured evidence without running handlers.
- Native source compiles to a typed AST and bytecode, executes within explicit
  budgets, and compares its outputs with a separate AST evaluator. Standalone
  programs support exact rational/polynomial operations and literal text
  transformations. Shared dependencies are declared; agreement is not a proof.
- Intake keeps original bytes, spans, recognized structures and unresolved text.
  The browser form uses the same guarded API. Explanations preserve computed
  values and domain limits; hostile markup remains text.
- Astra supplies source-pinned geometry and the supported evidence-atom state
  transitions. Its missing durable ATOM checkpoint support is an explicit refusal.
- HTTP admission bounds handlers and connection rate before parsing. Operational
  logs contain fixed categories, status and opaque request IDs. A rate limit on
  receipt recovery retains the pending command's exact ID.
- The new Book of Forms has eight chapters, 12 executed exercises and a complete
  source-linked 62-topic atlas. Unimplemented topic capabilities remain visible.
