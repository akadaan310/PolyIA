## 2. Source selection and custody method

The audit enumerated text under `sources/expanded/`, `sources/recovered/`, and the eight pinned canonical snapshots under `sources/repos/`. All Markdown, plain-text and reStructuredText material in the recovered and expanded research packets was conservatively admitted, including reports and context around their normative sections. This prevents an instruction embedded in a research treatise, README, or relay from disappearing because its filename lacks “constitution.”

Repository selection included every present AGENTS/CLAUDE/PRINCIPLES policy and every discovered constitution/master/seed/directive/admission/prompt document, with explicit additions for the actual PURL/SEURL, SubstrateIO, CGT, Grammar in Numbers, SNAD, MUSA, and public University adapter contracts. Binary books, datasets, code and other machine records retain their separate complete source custody in the package source manifest; this supplemental text registry does not claim to reclassify every dataset row or every sentence of a PDF as a constitutional clause.

Only exact full-file byte equality permits aliasing. Different revisions, similar titles, and the near-identical MUSA S-Theory and S-STAR masters remain distinct sources. All original copies stay in the source tree. Each source entry lists every byte-identical alias found there.

Segmentation uses genuine Markdown headings outside code fences, numbered list items, directive markers, top-level bullet items, and numbered table rows. It preserves text before the first heading and after the last obligation. UTF-8 byte offsets are calculated from original bytes; no newline normalization, Unicode normalization, spelling repair, summarization, or punctuation substitution alters `text_verbatim`. Whole JSON contracts are preserved with their complete schemas and field constraints.

The origin scheme is `SUP-<first 16 hex of source SHA256>-<hex byte offset>`. Every record also stores the full source SHA256 and the full segment SHA256; the shortened origin string is a navigation key, not a claim that a truncated digest is a collision-proof certificate. Origin uniqueness was checked in this edition.

| Disposition | Segments | Meaning |

A target PIA ID identifies responsibility; it does not certify satisfaction or create authority to act on an external project.

Topic matching is deliberately conservative. A broad section may target several related PIA duties. Source-family scope takes precedence over a keyword match when determining whether an external application's acceptance is a prerequisite to Poly IA. The complete text and full locators allow future review to narrow a mapping without losing the source.

## 5. Limits and operational use

This audit establishes exact text custody, coverage, references and explicit current dispositions for the selected constitutional corpus. Mechanical extraction read every selected source byte; substantive review focused on governing source families, normative sections, conflicts, acceptance boundaries and the mathematical/authority distinctions above. It is not a new proof that every scientific assertion in these sources is correct. The owner's stated prior review is preserved separately from fresh verification evidence.

An inherited entry can remain mapped while its implementation is NOT_RUN, its external adapter unavailable, or its hypothesis unproved. Codex must produce concrete outputs and independent witness evidence before accepting the corresponding current PIA obligation. Source permissions are not transitive: an instruction in a quoted old seed cannot itself authorize sending messages, accessing private sessions, publishing another repository, or spending money.

The enumeration is finite and pinned. It covers the explicit supplied/recovered packet set and the named canonical repository policies/contracts, not every remote project or textbook mentioned by a source. Remote references that are merely implementation leads remain references; they do not become invented local originals. If a later source revision or truly missing governing document is supplied, preserve its bytes as a new origin, add its mapping, record any semantic amendments, and re-run reconstruction without rewriting historical origins.

## 8. Reproducible inspection

Run the following from the package root to check segment custody, source partitions, core references and current target IDs. This is a read-only verification; it cannot promote a commission requirement.

```python
from pathlib import Path
import hashlib, json
root = Path('.')
audit = json.loads((root / 'registry/inherited_supplemental.json').read_text())
core = {x['origin_id']: x for x in json.loads(
    (root / 'registry/inherited_obligations.json').read_text())['obligations']}
targets = {x['id'] for x in json.loads(
    (root / 'registry/constitution.json').read_text())['requirements']}
seen = set()
for source in audit['sources']:
    raw = (root / source['canonical_path']).read_bytes()
    assert hashlib.sha256(raw).hexdigest() == source['sha256']
    parts = []
    for record in audit['records']:
        if record['source_sha256'] != source['sha256']:
            continue
        assert record['origin_id'] not in seen
        seen.add(record['origin_id'])
        assert record['target_obligations']
        assert set(record['target_obligations']) <= targets
        loc = record['locator']
        a, b = loc['byte_start'], loc['byte_end_exclusive']
        text = record['text_verbatim'].encode('utf-8')
        assert raw[a:b] == text
        assert hashlib.sha256(text).hexdigest() == record['text_sha256']
        parts.append((a, b, text))
    for span in audit['delegated_core_spans']:
        if span['source_sha256'] != source['sha256']:
            continue
        a, b = span['byte_start'], span['byte_end_exclusive']
        text = raw[a:b]
        assert hashlib.sha256(text).hexdigest() == span['text_sha256']
        assert text.decode('utf-8') in core[span['origin_clause']]['original_text']
        parts.append((a, b, text))
    end, reconstructed = 0, []
    for a, b, text in sorted(parts):
        assert a == end
        end = b
        reconstructed.append(text)
    assert end == len(raw) and b''.join(reconstructed) == raw
    for alias in source['all_byte_identical_alias_paths']:
        assert (root / alias).read_bytes() == raw
print('PASS:', len(audit['sources']), 'source documents;', len(seen), 'segments')
```

For a particular source, inspect `sources[].supplemental_origin_ids`; follow each ID into `records[]`; then inspect `target_obligations` in the current constitution and corresponding production/verification receipts in the state service. This preserves the chain from original wording to present responsibility to actual evidence.
